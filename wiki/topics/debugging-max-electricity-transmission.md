# The Problem

The max investments in electricity grid that I made using the TYNDP2024 reference
grid + candidates before 2040 turned infeasible when constraining.
This can be due to one of two things:
1. We have previously populated XKFX with the sum of reference- and *all* candidates in TYNDP reports, which obviously makes XKFX large.
2. We used the maximum value between two nodes, making capacities symmetrical and higher than TYNDP assumptions.
3. I made some error in calculating the maximum investment candidates
